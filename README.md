## 📌 Projetos em destaque

### 🚚 NALM

Sistema logístico desenvolvido para gerenciamento de fretes, equipes e motoristas.

A solução possui um painel para empresas e uma aplicação para motoristas acompanharem viagens, quilômetros percorridos e ganhos.

**Stack:** React • React Native • Node.js • PostgreSQL

🏆 Projeto campeão na categoria **Trabalho e Tecnologia da Feira do IFSP**.

### 🛒 Meliar

E-commerce colocado em produção, incluindo painel administrativo para gerenciamento de produtos, estoque, imagens, pedidos e configurações da loja.

**Stack:** Next.js • TypeScript • Supabase • PostgreSQL • Vercel

O projeto já recebeu centenas de usuários e milhares de visualizações de página desde sua publicação.
